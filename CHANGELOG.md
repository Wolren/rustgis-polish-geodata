# Changelog

## 0.2.1 - 2026-11-11

### Changed

- The pre-download count and the byte limit warn and keep what fits; the run returns the partial layer.
- The tool box clamps to the area the services hold; a box clear of Poland stops with the reason.
- The layer catalogue answer drops `max_span`.

### Fixed

- A clamped box drops the world polygon filter, which the Polish services answer with no feature.

## 0.2.0 - 2026-11-10

### Added

- The 8 GUGiK WCS coverages and `dodaj-wcs` for any GetCoverage URL.
- `wmts`: a GetTile template or a capabilities URL; a bare click adds the national ortho.
- `bdot500` and `gesut`: the county commands read the panel unit or the view.
- The pre-download count: a run over the feature cap refuses and names both ticks.
- The register: the 50 000 feature cap and the axis retry.
- The area box placement and the KINR and Osnowa flags.

### Changed

- The tool forms pick a common dataset by default; the numeric fields read floats and integers.
- The GeoPackage save needs an explicit path; the button left the ribbon.
- The byte limit: 0 means no limit; the ceiling is 256 MB.

### Fixed

- A dropped page or cell retries once, so the country download returns all 2 479 gminy.
- The feature-cap message fires only when the cap cuts the run.
- The 32 tile-layer limit names the fix.
- The empty area, the clip, the rectangle and the off-Poland answers name the next step.
- The sheet tool keeps only the controls it reads.

## 0.1.4 - 2026-11-09

- The unit tree, the typed download in one call, ten WMS menus and the bounded register update.

## 0.1.1 - 2026-11-08

- One menu level in the WMS group, so the registry accepts the tab.

## 0.1.0 - 2026-11-08

- The first release: the national raster overlays and WFS layers, the county EGiB, the register, the elevation, and the ULDK, UUG and NMT lookups.
